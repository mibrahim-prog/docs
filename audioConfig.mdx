# Audio Config

## What is Audio Config?

Audio Config allows you to manage how Xperia identifies the **agent's voice** and the **customer's voice** in a call recording.

You can choose whether the **agent's voice is on the Left channel or Right channel**.

Once the configuration is saved, it will be applied to newly uploaded calls.

---

## How to Configure Audio

### Step 1: Open Audio Config

Go to the **Audio Config** page.

![Audio Config page](/Images/step1.png)

---

### Step 2: Click Edit Setting

Under **Recording Channels**, click the **Edit Setting** button.

![Click Edit Setting](/images/audio-config-edit.png)

---

### Step 3: Turn On the Toggle

Turn on the **Dual-channel (stereo) recordings** toggle.

![Turn on toggle](/images/audio-config-toggle.png)

---

### Step 4: Select the Agent Channel

Choose which channel contains the agent's voice:

**Which channel is the agent on?**

- **Left channel** — Select this if the agent's voice is on the left channel.
- **Right channel** — Select this if the agent's voice is on the right channel.

![Select agent channel](/images/audio-config-channel.png)

---

### Step 5: Save the Changes

Click **Save** to apply your Audio Config settings.

After saving, the configuration will be used for **new calls that are uploaded or imported**.

---

## How It Works

Once the configuration is saved and a call is uploaded:

- The selected channel is treated as the **agent's voice**.
- The other channel is treated as the **customer's voice**.

For example:

**Agent → Left**  
**Customer → Right**

or

**Agent → Right**  
**Customer → Left**

> **Note:** This configuration applies to new calls. Existing call scores are not changed.
