## Overview

The Xperia Dashboard provides a central view of call activity, scoring results, agent performance, and important events.

It contains three main tabs:

- **Analytics:** Review call metrics, scoring trends, and agent performance.
- **Custom Parameters:** Review parameter results and pass rates.
- **Specialized Parameters:** Monitor important events and investigate matching calls.

## Dashboard Filters

Use the filters to narrow the displayed results.

- **Call Type:** Filter calls by type.
- **Department:** Select a department or all departments.
- **Agent:** Select an individual agent or all agents.
- **Time Range:** Choose the reporting period.

## Analytics

The Analytics tab provides an overview of call-center performance for the selected filters.

![Xperia Analytics Dashboard](/Images/Dashboard/DB-Analytics.png)

### Performance Summary Cards

The dashboard displays four key metrics:

- **Total Calls:** The total number of calls in the selected period.
- **Average Score:** The average score of the calls.
- **Dead Calls:** The number of calls classified as dead.
- **Fatal Incidents:** The number of calls associated with fatal incidents.

### Score Trend

![Score Trend](/Images/Dashboard/DB-ScoreTrend.png)

Shows how call scores change over time. Use the trend to identify increases or decreases in performance.

### Agent Analytics

![Agent Analytics](/Images/Dashboard/DB-AgentAnalytics.png)

Compares displayed scores across agents. Use the Show selector and pagination to view more agents.

### Score Distribution

![Score Distribution](/Images/Dashboard/DB-ScoreDis.png)

Shows how calls are distributed across score ranges. Taller bars mean more calls fall within that range.

### Category Scoring Overview

Shows the scores for performance categories on a **0–5 scale**. Use the category selector to choose a category and review its results.

### Category Parameters

![Category Parameters](/Images/Dashboard/DB-Category.png)

Compares the average score calls received with the average maximum score available for each parameter.

- **Average Obtained Score:** The average points calls actually received for a parameter.
- **Average Out Of Score:** The average maximum points available for that parameter.

**Example:** If the obtained score is **3.52** and the out-of score is **4.2**, calls received an average of 3.52 out of 4.2 possible points.

## Custom Parameters

![Custom Parameters](/Images/Dashboard/DB-Custom.png)

The Custom Parameters tab displays configured parameters and their results for the selected filters.

### Custom Parameter Information

- **Parameter Name:** The name of the configured parameter.
- **Total Values:** The number of recorded parameter values.
- **Pass Rate:** The percentage of results that satisfy the parameter.
- **True Results:** The number of results evaluated as true.
- **Total Results:** The total number of recorded results.

Each card compares true results with total values to help you understand how often a parameter is satisfied.

## Specialized Parameters

![Specialized Parameters](/Images/Dashboard/DB-Specialize.png)

The Specialized Parameters tab displays configured events, risks, behaviors, and signals identified during call analysis.

### Specialized Parameter Information

- **Parameter Name:** The event or behavior being monitored.
- **Flagged Percentage:** The displayed percentage of calls flagged for the parameter.
- **Call Count:** The number of matching calls compared with the total calls shown.
- **Progress Bar:** A visual representation of the flagged percentage.
- **Signal Indicator:** Shows whether the parameter represents a warning or a positive signal.

### View Calls

1. Open the **Specialized Parameters** tab.
2. Find the parameter and select **View Calls**.
3. Review the matching calls on the Call Scoring page.

The displayed calls depend on the selected parameter, available call data, and applicable filters.

### Add a Specialized Parameter

Select **Add Parameter** to begin configuring a new specialized parameter. Available options depend on your Xperia setup and permissions.

## How to Use the Dashboard

1. Select the required filters.
2. Review the performance summary and scoring charts.
3. Compare agent and category results.
4. Review custom parameter pass rates.
5. Investigate specialized parameters and open matching calls.

Use the charts to identify areas for further review, then examine the relevant calls and scores before drawing conclusions.
